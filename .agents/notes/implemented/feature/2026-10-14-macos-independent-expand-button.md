# Agent Note: macOS 展开按钮独立于页码显示

Status: implemented

## Problem

#7775 中，用户为了紧凑候选窗口隐藏页码与翻页键后，展开按钮一起消失，鼠标没有多行候选入口。

## Decision

共享偏好新增 `show_candidate_expand_button`，默认开启。开启「展开候选」后设置页显示「显示展开键」，独立于页码开关。普通候选首行已有拼音、图标或页码时放在首行右端；首行全部隐藏时放在候选行右端，不增加一行高度。关闭展开键只隐藏鼠标入口，下键仍能展开。

原生设置与共享设置读写同一个字段。旧文档缺字段读成开启，其它平台保留字段但不绘制。

历史检索：[展开候选网格](../../implemented/feature/2026-10-12-macos-expanded-candidate-grid.md)部分重叠，独立按钮取代绑定页码的规则，网格按键、代次和收起规则保留，候选首行与页码显示记录继续保持全隐藏不占首行高度。

## Alternatives considered

恢复页码和翻页按钮最容易提供鼠标入口，但违背用户为了缩小窗口关闭它们的选择；因此只显示独立展开键。

把展开按钮一直放在第二行可复用现有首行布局，但全隐藏时仍增加高度，改用候选行的尾部位置。

## Verification

共享文档缺字段默认为真并可保存关闭；设置只在展开开启时显示该项；原生回归覆盖页码隐藏仍可点击展开、关闭按钮后仍可下键展开、紧凑窗口不多出首行。

## Consequences

增加字段会被旧版严格偏好解析器拒绝；展开键所在候选行略宽，窄屏按剩余宽度折行，避免超出屏幕。
