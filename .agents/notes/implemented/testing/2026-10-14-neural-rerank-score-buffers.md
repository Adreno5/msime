# Agent Note: 神经整句重排的有界评分栈缓冲

Status: implemented

## Problem

`NeuralReranker::rerank` 最多评分12条路径，却为文本引用、神经分、静态分和混合分申请临时向量；静态分和排列还按完整路径数建立，随后访问未评分尾部。按键重排反复承担这些临时成本。评分缓冲收紧后，评分前缀排列仍每次申请一个索引 `Vec`。

## Decision

四份评分中间存储使用 `MAX_RERANK_PATHS` 长度的栈数组。评分前缀排列也写入调用方的固定索引缓冲，模型入口只对已评分前缀建立排列并原地应用，完整尾部不访问、不移动。测试专用的 `rerank_order` 仍返回完整拥有排列，保留长度检查、自然对数公式、`total_cmp` 稳定排序和尾部恒等映射；模型返回的平均分向量仍由模型接口拥有。

## Existing decisions

已检索活跃树的 `rerank_order`、评分上限和栈缓冲。[候选重排文本引用栈缓冲](../../implemented/testing/2026-10-09-rerank-text-buffer.md)是同仓库借用数组参考，入口不同；[神经路径原地重排](../../implemented/testing/2026-10-08-neural-paths-inplace.md)部分重叠，继续复用路径存储；[自然对数评分单位](../../implemented/bug-fix/2026-10-14-neural-lattice-score-units.md)保留公式、0.5权重和12条上限。九键数字网格提案无关，没有完全吸收或过时提案。

## Alternatives considered

- 只把向量容量缩到12：局部、容易保留接口；不采用，因为每轮仍申请四份临时堆缓冲。
- 在重排器对象上保存可复用向量：减少热查询分配；不采用，因为调用方栈数组已经覆盖固定上限，不需要额外跨查询状态和失效管理。
- 改用不稳定排序或只比较首选：可减少排序工作；不采用，因为同分稳定性、全部评分路径顺序和尾部保持均是已有契约。

## Verification

冻结基线 `7384a93f0eceea679aa61219cfa6d0e827117a25` 的完整排序与模型入口，只改名和转接冻结排序。两条精确分配测试在旧生产实现上真实失败：合法排序实际2次而预算1次；真实模型2条冷查询旧新均293次，未达到少4次的要求。新增栈索引测试在旧生产实现上因缺少 `rerank_order_into` 无法编译，改后零分配通过。改后真实模型78组重排均比冻结入口少5次（空/单条仍0次），纯排序对照保持通过。

纯排序520组覆盖0、1、2、3、6、11、12、13、15、64、128、129、4096条、五种评分长度、同分、正负零、正负无穷和不同符号NaN，验证完整排列、容量和尾部映射，合法调用2→1次分配，无效调用均0次。

真实键盘模型78组覆盖三种上下文（含Unicode与超过64字的截断）、13种路径长度和冷热缓存；路径含空文本、ASCII、Unicode及emoji。模型由仓库脚本按 `resources/neural-model.lock.json` 校验大小与SHA256后取得，通过 `MSIME_NEURAL_MODEL_DIR` 显式运行，未跳过。对照返回值、每个字段、浮点位模式、外层指针/容量及每条路径字符串、词列表、内层字符串的原始指针/容量，并验证尾部座位不变。先前尾部容量断言误把调用前克隆值与源值比较，`String::clone` 缩容触发夹具失败；现在记录实际入参原始存储。

至少两条路径的每次模型入口精确少5次分配；超过128条且冻结排列发生移动时，额外移除旧完整排列的访问缓冲，仍少5次；空/单条均0次。模型返回平均分向量仍保留，模型入口不再拥有索引排列。

第二轮完整 `MSIME_NEURAL_MODEL_DIR=$PWD/target/neural-model cargo test -p msime-engine --no-fail-fast` 退出0：2051项单测通过、16项既有忽略，31项黄金用例和文档测试通过。Clippy全目标 `-- -D warnings`、Rustfmt、差异检查和905篇笔记校验通过；quick门禁退出0，Android目标/Java宿主、WASM、macOS原生工程与共享Apple桥编译通过，Linux缺Docker、Windows交叉/pipe-only缺MinGW、HarmonyOS完整编译及设置bundle缺环境而跳过。新增栈索引测试与6144组空来源对照、1446组神经合并对照均通过。

## Consequences

增加固定栈空间约576字节（文本引用192字节、三个96字节评分数组和12个8字节索引，64位目标），实际帧由编译器布局决定。小排序的无额外堆申请是固定工具链行为，分配回归保护；不承诺CPU、RSS或设备延迟收益。不修改模型文件读取、推理、评分单位或公开API。

测试专用纯排序仍生成完整排列；模型入口仅生成和应用评分前缀，使尾部长度不再增加本层静态分、排列或访问标记的临时存储。通用大排列规则仍见[排列循环线性遍历](2026-10-12-order-permutation-linear-cycles.md)。上述精确分配结果使用固定Rust 1.97.1，不把小排序的栈实现视为所有工具链保证。

[神经合并借用排列](2026-10-14-neural-lattice-borrowed-order.md)移除每个键盘重排器的完整路径深复制，评分、去重和输出块规则继续沿用本篇约束。
