# Agent Note: 双拼纠错码投影复用栈缓冲

Status: implemented

## Problem

`ShuangpinDictionary::merge_sentences` 在每次启用双拼纠错的查询中把已验证的两键分段收集到临时 `Vec<&str>`。这些引用只在本次词网格合并中读取，常见输入的容器没有跨调用价值，却会在每次刷新申请一次堆存储。

## Decision

`typo_codes` 用固定的栈上引用数组保存常见的两键分段，并通过 `as_slice` 交给既有的双拼纠错边规划。超过栈容量的超长输入才创建 `Vec`，非法分段、手动分隔符和纠错关闭仍返回空投影；分段数量、每段长度和传入边规划的顺序保持不变。

本决定只改变临时引用容器的存储位置，不改变双拼纠错的变体表、跨度查询、缓存键、候选顺序或纠错准入。

## Alternatives considered

- **继续使用 `Vec<&str>`**：实现最简单，但每次常见双拼纠错刷新都会为只读引用申请短命堆存储。
- **为所有输入永久扩大栈数组**：可以覆盖更长输入，但会让每次合并都携带更大的栈帧；采用小的常见输入上限，并为超长输入保留堆回退。
- **让边规划按分隔符反复扫描原始字符串**：可以取消容器，但会把一次索引读取变成重复字符串扫描，且扩大纠错边模块的输入契约；不采用。

## Consequences

- **收益**：典型三音节双拼纠错码投影不再申请临时堆向量，既有边规划继续读取同一组 `&str`。
- **代价与已知上限**：超过固定栈槽位的超长输入仍分配 `Vec`；栈数组始终占用固定引用槽位，若输入长度分布显著增大需要重新评估槽位大小。

## Verification

- 红测试在旧实现上确认典型投影产生 1 次分配。
- 改后定向分配测试确认典型投影为 0 次分配，并保留现有 `shuangpin` 纠错行为测试覆盖。
