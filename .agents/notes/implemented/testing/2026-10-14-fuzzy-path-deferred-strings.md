# Agent Note: 模糊路径字符串延后拥有

Status: implemented

## Problem

模糊 beam 已将变体规划改为借用，但中间路径仍拥有字符串。每个需要复制的父路径都深拷贝非空前缀，截断丢弃父路径和过滤原组合时释放这些临时副本；最终路径只需要各拥有一份实际返回字段。

## Decision

内部路径保存借用的 `Cow<str>`，按原规则展开、复用父路径/单变体层并过滤原组合；只对保留下来的完整路径调用 `Cow::into_owned`。沿用首分叉前延后初始化及零容量必空结果。逐层向量仍按原 `push`/预留策略建立，消费式 `map().collect()` 在固定工具链上复用等布局的内外层向量，避免额外创建最终路径容器。返回 `Vec<Vec<String>>` 独立拥有全部内容。

## Existing decisions

已检索模糊路径、变体规划、单变体、`Cow` 与延迟拥有。与[父路径复用](2026-10-09-fuzzy-path-reuse.md)和[变体视图](2026-10-14-fuzzy-variant-views.md)部分重叠，保留其展开/容器复用，翻转中间路径拥有字符串的时机；与[延后原切分](2026-10-14-fuzzy-beam-lazy-start.md)部分重叠，保留延迟首分叉及必空零分配，非空成本进一步降低。[输入音节借用](2026-10-14-fuzzy-input-segments-borrow.md)、读法前缀和行缓存属于独立层；其冻结预算在计量外补偿本次字符串节省。自动纠错和九键切分来源无关，没有完全吸收或过时提案。

## Alternatives considered

- 内部路径直接用 `&str`：槽更小、类型简单；未采用，因为它转为 `String` 时需要新的行向量，短路径节省的字符串可能少于新容器数。
- `Arc<str>` 共享前缀：最终路径可以共享字符串，避免深拷贝；未采用，因为返回接口仍为 `String`，增加计数及初始共享分配，且这里已有输入/静态音节可借用。
- 继续拥有并只优化原组合：容易保留现有存储形态；未采用，因为层间复制和截断父路径仍产生无消费者副本。

## Consequences

共享 n 元表淘汰的后续受控证据见[活动词典保留已预热表](2026-10-14-active-dictionary-ngram-tables.md)：它能稳定触发相同两次额外申请，活动词典改为保留构造句柄；本篇原失败的现场时序仍未被记录。

`Cow<str>` 与 `String` 的等布局和消费式收集复用属于工具链实现细节，不是标准库永久 ABI 契约；固定 `1.97.1` 工具链在本机实测均24字节，消费式转换保留容量及底层分配。回归对照限制分配/容量，升级工具链时变化会被测出。引用只能来自输入或静态音节，不能借用六字节拼接缓冲；转换在返回前完成。不主张 CPU、RSS 或设备延迟收益。

沿用标准库 [Cow::into_owned](https://doc.rust-lang.org/std/borrow/enum.Cow.html#method.into_owned) 的拥有结果及 [消费式收集实现](https://doc.rust-lang.org/src/alloc/vec/in_place_collect.rs.html) 的现有复用；无新依赖、unsafe、跨查询状态或 crate 对外接口变化。
