# Agent Note: 双拼单字辅助码匹配分类复用栈缓冲

Status: implemented

## Problem

双拼单字辅助码过滤先为每个候选计算 `SingleHelpcodeMatch`，再把这些只读一次的匹配分类收集到临时 `Vec`，交给原地重排。常见候选批次很短，却仍为分类向量申请一次堆存储；已有的重排索引栈缓冲只覆盖后续 `usize` 排列，未覆盖这份分类状态。

## Decision

`single_helpcode_matches` 对不超过 64 行的批次使用固定栈数组，并通过切片交给既有重排函数；超过边界时按候选数创建 `Vec`，保持长批次的可扩展性。分类顺序、大小写偏好、未匹配尾部和双辅助码路径保持不变。

## Alternatives considered

- **继续使用 `Vec<SingleHelpcodeMatch>`**：实现最直接，但每次短辅助码查询都会为一次性分类状态分配堆内存。
- **为所有输入使用固定大数组**：可避免长批次分配，但会把不常见长输入的栈帧扩大；保留超界堆回退以维持现有边界。
- **把分类重新计算到每个重排循环**：可以省去分类容器，但会重复查辅助码并把一次计算变成多轮扫描；不采用。

## Consequences

- **收益**：常见单字辅助码批次不再为匹配分类申请临时堆向量。
- **代价与上限**：长于 64 行的批次仍申请一份与候选数相称的 `Vec`；短路径固定占用少量栈空间。

## Verification
