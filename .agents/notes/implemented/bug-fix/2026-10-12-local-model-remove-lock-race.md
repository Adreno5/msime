# Agent Note: 本地语音模型删除拒绝跨进程安装竞态

Status: implemented

## Problem

本地语音模型安装和删除共用根目录锁，但 host-api 的“正在安装”登记表只存在于当前进程。另一个宿主进程安装模型时，删除请求会等待安装释放锁，随后删除刚发布的模型；这与 `local_model_install_running` 的接口契约不一致，也会让用户刚完成的下载立即消失。

## Decision

删除模型在拿到根目录后以非阻塞方式尝试取得同一个模型锁。锁被其他安装持有时返回 `local_model_install_running`，不清理暂存目录，也不等待安装完成。安装仍然使用阻塞锁，保持原有的跨进程串行写入；删除成功后继续沿用原子改名和目录句柄清理。

## Alternatives considered

- **继续等待锁再删除** — 能保证删除请求最终完成，但会把“删除”悄悄作用到另一个进程刚发布的模型，违背 host-api 已公开的忙碌错误码，因此不采用。
- **新增跨进程安装登记文件** — 可以区分安装者和锁竞争，但需要处理崩溃遗留、清理和符号链接安全；现有锁已经提供可靠的忙碌信号，增加登记文件没有必要。

## Consequences

- **收益**：跨进程删除不会再误删正在安装的模型；调用方收到现有的 `local_model_install_running` 错误并可稍后重试。
- **代价与已知上限**：删除在锁竞争时失败而不是排队，设置页需要按现有忙碌错误提示重试；锁文件异常仍按原有 I/O 错误处理。

## Verification

`voice::local_models` 的 77 项测试通过，其中新增用例在持有模型锁时验证删除立即返回 `InstallRunning`，并更新并发安装用例确认安装完成后模型仍保留；host-api 的两个本地模型 FFI 测试通过。
