# Agent Note: 脚本变换区分重复候选

Status: implemented

## Problem

[脚本插件的候选变换](../architecture/2026-10-12-script-plugins-modify-commit-and-candidates.md)原先用文本和来源作为身份。同一列表里两行文本、来源相同时，插件隐藏、重排或注释其中一行会误作用于另一行。引擎允许这种重复行；插件收到的是行号，操作的目标应当是那一行。

旁路刷新原先还为完整列表的每一行复制文本和编码，即使插件没有记录操作；大列表的身份重建因此产生逐行堆分配。插件只收到前 20 行，但发生重排后重复候选可能跨越这个窗口，不能用缩小身份范围来省掉复制。

## Decision

`input-runtime` 用文本、来源、编码和同组候选在引擎原始顺序中的出现序号识别一行。实际记录操作时或旁路重放前，依照 `engine_order` 为完整候选列表重建同组出现序号，插件窗口行号立即映射到该身份；隐藏、重排和注释都用同一身份匹配。只有被插件点名的行在操作记录中保存拥有文本和编码的完整身份；当前列表保留平行的 `Vec<usize>` 出现序号，匹配时借用快照里的文本、来源和编码。插件重排时出现序号与候选平行移动，注释始终跟着原行。旁路刷新重建出现序号并重放操作，不运行脚本。插件照常收到前 20 行窗口；没有交回任何操作时，不构造全列表身份元数据。

出现序号由引擎顺序决定，而非当前显示座位，所以内置排序或插件重排不会把两个重复行的操作交换。在线候选插入其他文本时不会改变这一组的编号。若引擎把一个无法区分的新重复行插在同组前面，旧操作会按新的同组序号对应；没有引擎提供的持久行 ID，就不能从相同文本、来源、编码中识别旧行。

## Testing

`candidate_transform` 回归测试构造两条同文同来源同码候选，验证只隐藏点名的一条、另一条的注释独立保留、旁路刷新仍对应原行；另一用例验证两条重复行可按插件指定的顺序重排，注释随原行移动。大列表用例把引擎的第二条重复移到首屏、把被注释的第一条移到 20 行插件窗口之外，再在旁路刷新中插入其它文本，验证操作仍按引擎出现序号对应，旁路调用不运行插件。

分配预算通过同线程计数器只测 `transform_candidates`，不计快照、视图或插件脚本本身的分配。旧实现的 32、1,024、4,096 行单注释重放分别分配 71、2,060、8,206 次，预算测试失败；优化后为 7、12、14 次。没有记录操作的 1,024 行旁路刷新从 2,060 次分配降为 0。

`cargo test -p msime-input-runtime --locked` 通过 253 项单测及文档测试；宿主 `script_plugins` 测试通过 60 项、忽略 2 项。`cargo clippy -p msime-input-runtime --locked --all-targets -- -D warnings`、Rustfmt 与笔记校验通过。`scripts/verify-local.sh --quick` 通过，包含 Rust 工作区、Android target、Wasm、Android 宿主 Java 冒烟、macOS 原生宿主和共享 Apple 桥接编译；Linux 缺 Docker、Windows 缺 MinGW、HarmonyOS 缺真编译工具链与预置资源而跳过。这些结果不代表设备输入法验收。

## Alternatives considered

- **只给身份增加编码。** 读取窗口已有的编码，代价低；但同码重复行仍会互相串操作，不能修复回归用例。
- **直接保存引擎下标。** 同一次刷新里可唯一指向一行；但旁路刷新插入候选后下标可能变化，旧操作可能落到另一条候选。按同组出现序号重建可跨其他候选的插入保持对应。

- **只为前 20 行建立出现序号。** 缓冲更小，但内置重排可能把引擎顺序较后的重复行提到首屏；必须遍历完整列表才能保持同组序号，注释才能在窗口内外移动时仍跟着原行。
- **把借用字符串保存在插件状态中。** 可省掉被点名行的复制，但快照在刷新时会被替换、排列；跨刷新记录必须拥有文本和编码。仅在一次匹配中借用当前快照，保存的操作仍拥有完整身份。
- **继续为每行保存完整身份。** 匹配只需结构体相等判断，但每次刷新都会复制整张列表的文本和编码，插件无操作时也付出同样成本。

## Consequences

重复候选的操作按行生效；有操作时仍按引擎顺序遍历完整列表，但当前列表的身份缓冲只保存出现序号，逐行文本和编码的复制被取消。保存的操作仍拥有被点名行的完整身份，跨刷新重放规则不变。出现序号的排序与哈希计数成本仍存在；没有插件操作时跳过它们。引擎不提供持久行 ID 的限制仍然存在。
