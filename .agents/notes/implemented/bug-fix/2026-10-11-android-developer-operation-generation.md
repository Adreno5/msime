# Agent Note: Android 开发者云端操作丢弃过期回调

Status: implemented

## Problem

开发者诊断页的上传、删除云端日志和重生成访问令牌都走独立的网络线程，但回调没有绑定发起操作的页面代次。用户在操作等待期间返回页面、刷新或切换账号时，旧回调仍可能把云端状态和新令牌写回当前页面。

## Decision

每个云端操作在发起时递增页面代次，回调只在代次仍然一致时更新界面；过期回调仅解除忙碌状态，不显示旧结果。页面销毁和重新加载本来就会递增同一个代次，因此不会把旧操作结果交给新视图。

## Alternatives considered

- 只比较账号和会话 ID：同一账号刷新页面时仍可能让旧操作覆盖较新的云端状态。
- 取消网络线程：HTTP 请求可能已经进入系统网络栈，取消不能保证回调不再到达；回调代次检查仍然需要保留。

## Consequences

过期的网络操作仍会在后台完成，但不会污染当前页面；用户可以在刷新或账号切换后继续操作，旧回调只解除旧操作的忙碌标记。
