# Agent Note: Android 选择面板首次显示保留取消按钮

Status: implemented

## Problem

#7763 在识别服务选择面板中看到取消行落在系统导航栏下方，需要先向上拖动。选项多时，默认折叠位置没有给固定在列表之后的取消行留下屏幕空间。API 35 原生宿主的九项合成列表复现取消行超出导航栏安全区域。

## Decision

选择面板首次显示时直接展开，长列表在自己的滚动区滚动，标题和取消行留在面板内。保留 Material 系统栏内边距策略，不使用固定导航栏高度。

检索只命中[标点样式](../feature/2026-10-13-punctuation-mark-styles.md)中选择面板的调用，它不决定初始位置，保持不变。

## Alternatives considered

增加固定底部 padding 能给部分机型留空，但系统栏高度和面板折叠偏移不同，仍不能保证长列表的取消行可见，因此调整初始面板位置并用实际设备坐标验证。

## Consequences

长列表首次打开占用更多屏幕，仍可下滑关闭。设备测试在原生宿主打开九项合成列表，不拖动就检查整个取消行位于导航栏上方，并点击关闭；测试挂到设置验收流程。
