# uuid：插件指令的参考样板

在 `/` 指令里打 `/uuid` 或 `/guid`，给出同一个随机 UUID（版本 4）的四种写法。它是 `provide_commands`（在自己的 `/` 指令里出候选）和 `random_fill`（读宿主给的随机数）的最小样板，演示插件指令接口怎么用，不是主打功能：UUID 生成本身十几行就能做成内置功能，`crates/client-core` 也早就依赖 `uuid`，以后真要给所有平台用会做成内置的 `/uuid`。写自己的指令插件时，照着这个目录的结构和 `src/lib.rs` 改。

| 项 | 值 |
| --- | --- |
| 钩子 | `command` |
| 能力 | `provide_commands`（读你在它的触发词后面打的字母，给出候选行） |
| 指令 | `/uuid`（标题 UUID）、`/guid`（标题 GUID） |
| 许可证 | MIT |
| 模块 | 约 3.2 KiB，内存 2 页 |
| 分发 | 随 macOS、Windows、Linux 的桌面安装包分发（`plugins/official-packs.json`），默认停用；移动端安装包不带 |

插件读不到你平时打的字、上屏文本和候选窗口，也不改写任何文字；它只在你打了它的触发词时给出几行，由你选中才会输入。

## 用法

1. 在「插件 → 脚本插件（实验）」里打开 UUID，授予「提供 / 指令」。
2. 打开「输入 › 快捷模式」里的 / 指令（默认关），并使用中文标点。
3. 在全拼、双拼或五笔下没有输入时按 `/`，再打 `uuid`：

| 输入 | 候选（注释格） |
| --- | --- |
| `/uuid` | `3f2b8c1e-…`（UUID 小写）、`3F2B8C1E-…`（UUID 大写）、`3f2b8c1e…`（UUID 无连字符）、`{3F2B8C1E-…}`（UUID GUID） |
| `/guid` | 同一个值，GUID 写法排在第一行 |
| `/uuidx` | 插件不给行，只有原样的 `/uuidx` |

按序号、点选或空格选中一行就输入那一行，组字结束；打标点结束输入时输入高亮的那一行；按回车输入原文 `/uuid`。

## 规则

- **随机数**：每次投递 `command` 时，输入法从操作系统的 CSPRNG 取 64 字节交给插件，插件只读前 16 字节，按 RFC 9562 第 5.4 节把第 7 字节的高 4 位设成版本 4、第 9 字节的高 2 位设成变体 `10`。插件自己没有随机数来源，也不存任何状态。
- **同一次组字里不变**：输入法按预编辑串缓存插件给出的行，翻页、按方向键时不再问插件，行不变；删掉一个字母再打回来、或者重新进入 `/`，才会换一个新的 UUID。
- **在快照上运行**：`command` 每次都在 `msime_init` 之后的快照上运行，插件拿不到上一次投递留下的东西，输出只取决于触发词、参数和这一次的随机数。
- **参数**：触发词后面还有字母时不给任何行。参数最多 64 字节，插件读参数的缓冲区正好这么大。
- **不进词库、不计打字统计、不作为 AI 上文、不查释义、上屏不转全角**：这些是输入法对所有插件行的规则，见 docs/plugins.md 的「脚本插件」一节。

## 夹具与核对

`fixture.jsonl` 覆盖 `/uuid`、`/guid`、两份不同的随机数、全 0 和全 FF 的随机数，以及参数不为空的两种情况（含 64 字节的最长参数）。`scripts/test-script-plugins.sh` 除了按 `expected.jsonl` 逐行核对，还跑 `check_output.py`：它从夹具里的随机数独立算出 UUID（Python 的 `uuid` 模块），核对每一行的写法、顺序、注释，以及版本位和变体位。

## 最坏情况的 fuel

工作量是常数：读触发词和参数各一次、读 16 字节随机数、格式化四行（每行一个 16 次的循环）、交出四行、写一行日志。实测峰值约 9 400 fuel，远低于 `command` 单次上限 100 000 的一半（`check_run.py` 断言不超过 50 000）。

## 内容哈希

授权绑定在包的内容哈希上。官方包的哈希锁在 `plugins/official-packs.json` 里，`scripts/build-official-plugins.sh` 每次构建都核对：改了这个目录的源码或清单、升级了 `rust-toolchain.toml` 的编译器，哈希都会变，所有用户在下一个版本里都要重新授权。所以改它时要在同一个 PR 里更新锁，并在发版说明里写明。
